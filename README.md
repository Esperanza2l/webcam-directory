# Webcam Directory

Minimal WordPress plugin that shows a list of 3 demo webcams (name, category, status, link).

## Installation

1. Copy `webcam-directory.php` into `wp-content/plugins/webcam-directory/`.
2. Activate **Webcam Directory** in *Plugins*.

## Usage

Add this shortcode to any page or post:

```
[webcam_directory]
```
